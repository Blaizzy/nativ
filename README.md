- **Official website:** [runnativ.ai](https://runnativ.ai/)
- **Downloads:** [Nativ releases](https://github.com/Neywa-Labs/nativ/releases)

Please update your bookmarks and Git remotes:

```sh
git remote set-url origin https://github.com/Neywa-Labs/nativ.git
```

This repository preserves the old [GitHub Pages address](https://blaizzy.github.io/nativ/) and redirects visitors to the corresponding pages on **runnativ.ai**. Active development takes place in [Neywa-Labs/nativ](https://github.com/Neywa-Labs/nativ).

The static redirect pages are published from the repository root. They include immediate redirects and canonical links for the known pages, plus a fallback for other paths. Search engines update their results after recrawling these URLs.
